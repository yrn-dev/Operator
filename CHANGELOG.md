# Changelog

## [1.3.3] - 2026-11-09

- При запуске CLI проверяет официальный релиз и показывает реальные новинки.
  Новая версия ставится командой `opr update` прямо в терминале из официального
  GitHub Release, без ручной загрузки архива с сайта.

## [1.3.2] - 2026-10-30

- Нейтральные тёмная и светлая темы в стиле Desktop: серые акценты, монохромный код, спокойные рамки и меню.
- Уровень thinking больше не окрашивает рамку ввода. Приглушённые смысловые цвета сохранены для ошибок, предупреждений и diff.
- Убраны двойные разделители вокруг редактора и пустые счётчики в статусе.

## [1.3.1] - 2026-10-30

- Переписан системный промпт: ясная роль Operator, прямой характер, соразмерные действия и проверяемый результат.
- Добавлены реальные сведения об устройстве и инструмент system_info. Локальное хранение отделено от отправки контекста облачному провайдеру.
- Названия диалогов формируются локально, без дополнительного запроса к модели.
- Сокращён каталог скиллов в запросе без изменения их файлов; устранена повторная обработка старых ходов при проверке зацикливания.
- Раньше выявляются одинаковые ошибки и пустые повторные проверки; чтение фонового лога ограничено хвостом файла.
- Убраны списки ресурсов и What’s New при обычном запуске; --verbose сохраняет диагностику.

## [1.3.0] - 2026-10-30

- Перенесены встроенные субагенты, фоновые процессы, GitHub, браузер и экранное управление в CLI без Electron и без десктопных плагинов.
- Добавлены подтверждения опасных команд, точные правила разрешений, файловые checkpoints, многофайловый откат и просмотр diff.
- Добавлены фоновые диалоги с RPC, просмотр действий субагентов, диагностика, скрытый ввод ключей, автоматические названия, звуки и работающие хуки.
- Qwen всегда получает `enable_thinking: true`; переключатель reasoning убран из настроек и горячих клавиш.
- В локальную сборку включены подготовленные ранее исправления сжатия, восстановления и экономии контекста, защиты от повторов и продолжения ограниченных по длине ответов.
- Добавлены проверки SDK, политик, отката, процессов, браузера, субагентов и фоновых диалогов на изолированных данных.

## [1.2.3] - 2026-09-16

### Fixed
- Изображения с `qwen3-8`: вторая картинка в сессии (или две в одном запросе) давала ошибку 400 «At most 1 image(s) may be provided in one prompt», и сессия ломалась. Теперь в запрос уходят только самые свежие изображения в пределах лимита модели, более ранние заменяются текстовой пометкой.
- Несколько фото в одном сообщении для `qwen3-8` склеиваются в одну картинку с номерами — раньше модель видела только одно из них
- Модели Ollama с зрением (например `gemma4:cloud`) определяются по `capabilities` сервера, а не по имени — раньше картинки им не отправлялись

### Added
- Системный промпт знает официальные страницы: npm, GitHub и десктоп opr.pzero.kz (в том числе при своём SYSTEM.md)
- Инструмент `app_control` — управление приложениями через их собственные скриптовые API

### Removed
- Инструмент `deep_research` и все его упоминания в системном промпте

## [1.2.2] - 2026-08-19

### Added
- Новая модель Alem AI: `qwen3-8` (мультимодальная, 262K контекст)
- Доступна через `--model qwen3-8` или в TUI-селекторе моделей

### Removed
- Модель `qwen3-6` — заменена на `qwen3-8` (тот же провайдер, вдвое больше контекст: 262K вместо 131K)

## [1.2.1] - 2026-08-09

### Fixed
- Новые инструменты теперь действительно активируются по умолчанию в `createAgentSession` SDK (была пропущена точка входа SDK)
- `task_plan`, `task_update`, `task_list`, `memory_store`, `memory_recall`, `test_run`, `git_status`, `git_diff`, `git_commit` доступны в интерактивном и print-режиме

## [1.2.0] - 2026-08-09

### Added
- Новые инструменты агента:
  - `task_plan` / `task_update` / `task_list` — управление планом задач, хранится в `~/.opr/agent/tasks.json`
  - `memory_store` / `memory_recall` — долговременная память в `~/.opr/agent/memory/<slug>.md`
  - `test_run` — запуск тестов с автоопределением фреймворка (npm/pytest/cargo/go/gradle/dotnet)
  - `git_status` / `git_diff` / `git_commit` — нативные git-инструменты
- Инструменты активны по умолчанию и описаны в системном промпте
